# Reference

Reference documentation provides **complete technical specifications** for
Agentheon. Use this section when you need to look up an agent, a frontmatter
field, or a convention.

## Available Reference

- [Agent catalog and profile schema](agents.md)

## What's Reference Documentation?

Reference docs describe the technical machinery — agent profiles, the profile
frontmatter schema, routing, and engineering conventions. They're factual,
neutral, and comprehensive. Consult them while working, not for learning.
