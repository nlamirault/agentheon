# How-to Guides

How-to guides are **task-oriented** — they show you how to accomplish specific
goals in Agentheon. These guides assume you already know the basics.

## Available Guides

- [Install the pantheon into Hermes Agent](install-the-pantheon.md)
- [Add a new agent to the pantheon](add-a-new-agent.md)
- [Manage provider API keys with Bitwarden](manage-secrets.md)
- [Connect a knowledge vault (Obsidian, or any Markdown editor)](connect-a-knowledge-vault.md)

## What's a How-to Guide?

How-to guides solve a specific real-world problem. Unlike tutorials (which
teach), how-to guides assume you know what you want to do and just need the
steps.
