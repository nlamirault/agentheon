# Project structure

Standard directory layout for open source projects:

```text
project-name/
├── .github/
│   ├── workflows/
│   │   ├── release-please.yml
│   │   └── ossf-scorecard.yml
│   ├──  CODEOWNERS
│   └── release-please-config.json
├── hack/
│   └── header.txt
├── .editorconfig
├── .gitignore
├── .pre-commit-config.yaml
├── .release-please-manifest.json
├── CITATION.cff
├── CODE_OF_CONDUCT.md
├── CONTRIBUTING.md
├── DCO
├── LICENSE
├── licenserc.toml
├── Makefile
├── README.md
└── SECURITY.md
```
