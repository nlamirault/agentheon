# Example Infographic Prompts

This file contains complete, working examples of infographic prompts for Gemini, organized by use case and complexity.

## Example 1: Educational Timeline (Simple)

### Context

Target audience: High school students
Purpose: Teach key events in computer history
Platform: Digital display in classroom

### Complete Prompt

```text
Create an infographic with the following specifications:

Topic: History of Personal Computing
Audience: High school students (ages 14-18)
Purpose: Educational - teach key milestones in computer history

Title: "Evolution of Personal Computing: 1975-2025"
Title Position: Top center, large and bold

Visual Style: Flat design minimalist style with clean lines, solid colors, simple geometric shapes, and no gradients. Use a modern tech aesthetic with blues and grays.

Layout: Linear timeline flowing left to right with 6 major milestones. Each milestone should have an icon, year, and brief description.

Color Palette:
- Background: Light gray (#F5F5F5)
- Timeline line: Dark blue (#003366)
- Icons and accents: Bright blue (#0066CC)
- Text: Dark gray (#333333)

Content - 6 Milestones:

1. 1975 - "Altair 8800"
   Description: "First commercially successful personal computer kit"
   Icon: Computer with switches

2. 1984 - "Macintosh"
   Description: "First mass-market PC with graphical user interface"
   Icon: Classic Mac computer

3. 1995 - "Windows 95"
   Description: "Brought GUI and internet to mainstream users"
   Icon: Windows logo

4. 2007 - "iPhone"
   Description: "Revolutionized mobile computing with touchscreen"
   Icon: Smartphone

5. 2010 - "iPad"
   Description: "Created tablet computing category"
   Icon: Tablet device

6. 2023 - "AI Integration"
   Description: "AI assistants become standard in personal devices"
   Icon: Brain with circuit pattern

Dimensions: 1920x1080 pixels (horizontal, presentation format)

Additional Requirements:
- Icons should be simple, line-art style in bright blue
- Each milestone positioned evenly along timeline
- Year in large bold text above each icon
- Description in smaller text below each icon
- Ensure high contrast for projection visibility
- Minimum 24pt font for all text

Text Legibility:
- Timeline labels must be easily readable from 20 feet away
- Use san-serif font (Helvetica or similar)
- Ensure adequate spacing between milestones
```

### Why This Works

- **Specific content**: All text provided exactly, no AI-generated descriptions
- **Clear visual direction**: Flat design specified with color codes
- **Appropriate layout**: Linear timeline perfect for chronological content
- **Audience-appropriate**: Style and complexity match high school level
- **Technical specs**: Dimensions and format specified for intended use

## Example 2: Business Comparison (Medium Complexity)

### Context

Target audience: Business professionals
Purpose: Product comparison for sales presentation
Platform: Slide in PowerPoint presentation

### Complete Prompt

```text
Create an infographic with the following specifications:

Topic: Cloud Storage Solutions Comparison
Audience: Business decision-makers and IT professionals
Purpose: Compare three cloud storage providers for enterprise selection

Title: "Enterprise Cloud Storage: Feature Comparison"
Title Position: Top center

Visual Style: Professional minimalist with flat design style. Clean, corporate aesthetic with subtle shadows for depth. Use modern san-serif fonts and geometric icons.

Layout: Split screen divided into three vertical columns, one for each provider. Each column contains the same categories for direct comparison.

Color Palette:
- Background: White (#FFFFFF)
- Column dividers: Light gray (#E0E0E0)
- Provider 1 accent: Blue (#0066CC)
- Provider 2 accent: Green (#00AA44)
- Provider 3 accent: Orange (#FF6600)
- Text: Dark gray (#2C2C2C)
- Check marks: Green (#00AA00)
- X marks: Red (#CC0000)

Content - Three Columns:

Column 1: Provider A
- Storage: 5TB
- Users: Unlimited
- Security: ✓ End-to-end encryption
- Collaboration: ✓ Real-time editing
- Support: 24/7 phone + email
- Price: $25/user/month

Column 2: Provider B
- Storage: 3TB
- Users: Up to 100
- Security: ✓ End-to-end encryption
- Collaboration: ✓ Real-time editing
- Support: Email only
- Price: $15/user/month

Column 3: Provider C
- Storage: Unlimited
- Users: Unlimited
- Security: ✓ End-to-end encryption
- Collaboration: ✗ No real-time editing
- Support: 24/7 phone + email + chat
- Price: $35/user/month

Dimensions: 1920x1080 pixels (16:9 presentation format)

Additional Requirements:
- Each provider name at top of column in large bold text with accent color
- Feature categories aligned horizontally across all three columns
- Use checkmark ✓ and X ✗ symbols for yes/no features
- Highlight best value in each category with subtle background tint
- Include small icons for each feature category (storage, users, security, etc.)
- Footer: "All prices as of January 2026. Contact for enterprise discounts."

Typography:
- Title: 42pt bold
- Provider names: 36pt bold in accent colors
- Feature categories: 18pt semi-bold
- Feature values: 24pt regular
- Footer: 14pt italic

Visual Balance:
- Equal column widths
- Consistent vertical spacing between features
- Adequate padding around all elements
- Clean dividing lines between columns
```

### Why This Works

- **Business-appropriate**: Professional style and clear data presentation
- **Direct comparison**: Split-screen layout perfect for side-by-side comparison
- **Complete data**: All comparison points specified exactly
- **Visual hierarchy**: Typography sizes indicate importance
- **Usability**: High contrast and clear symbols for quick comprehension

## Example 3: Social Media Post (High Engagement)

### Context

Target audience: General public on Instagram
Purpose: Raise awareness about plastic pollution
Platform: Instagram post (square format)

### Complete Prompt

```text
Create an infographic with the following specifications:

Topic: Ocean Plastic Pollution Statistics
Audience: General public, ages 18-45, environmentally conscious
Purpose: Raise awareness and encourage action on social media

Title: "Ocean Plastic Crisis"
Subtitle: "By the Numbers"
Title Position: Top third of image, centered

Visual Style: Modern illustrated style with hand-drawn elements. Use ocean-themed colors with organic shapes and flowing lines. Mix of illustration and bold typography. Friendly but serious tone.

Layout: Circular flow with central statistic surrounded by 4 supporting facts arranged in clockwise pattern. Bottom section for call-to-action.

Color Palette:
- Background: Gradient from light blue (#E3F2FD) at top to darker blue (#1976D2) at bottom
- Main statistic: White text with dark blue (#003366) outline
- Supporting facts: White text on semi-transparent navy circles
- Icons: Teal (#00BCD4) and coral (#FF6B6B) accents
- Call-to-action: Coral (#FF6B6B) button

Content:

Center Statistic (Large):
"8 MILLION TONS"
"of plastic enter our oceans every year"

Supporting Facts (Around center, clockwise from top):

1. Top: "300 MILLION TONS"
   "of plastic produced annually"
   Icon: Factory

2. Right: "50% SINGLE-USE"
   "of plastics used only once"
   Icon: Water bottle

3. Bottom: "100,000 ANIMALS"
   "die from plastic each year"
   Icon: Sea turtle

4. Left: "450 YEARS"
   "for plastic bottle to decompose"
   Icon: Bottle with clock

Call-to-Action (Bottom):
"3 Actions You Can Take Today"
1. "Refuse single-use plastics"
2. "Choose reusable alternatives"
3. "Support plastic-free businesses"

Dimensions: 1080x1080 pixels (Instagram square format)

Additional Requirements:
- Central statistic must be dominant focal point, largest text
- Supporting facts in semi-transparent navy circles for readability over gradient
- Icons simple line-art style in teal color
- Call-to-action section at bottom with coral background for high visibility
- Use bold san-serif font for numbers, clean sans-serif for descriptive text
- Small attribution in bottom corner: "Source: UN Environment Programme 2024"
- Include small recycling symbol icon near title

Visual Effects:
- Subtle wave pattern in background gradient
- Slight shadow behind circular fact bubbles for depth
- Icons should have slight glow effect to stand out
- Overall feel: Serious but hopeful, informative but not overwhelming

Text Hierarchy:
- Center number: 72pt bold
- Center description: 24pt regular
- Supporting numbers: 48pt bold
- Supporting descriptions: 18pt regular
- Call-to-action title: 32pt bold
- Call-to-action items: 20pt regular
```

### Why This Works

- **Social media optimized**: Square format, eye-catching colors, shareable content
- **Emotional impact**: Central shocking statistic draws attention
- **Action-oriented**: Clear call-to-action encourages engagement
- **Circular layout**: Natural eye flow keeps attention on content
- **Platform-appropriate**: Mobile-friendly text sizes and high contrast

## Example 4: Process Workflow (Technical)

### Context

Target audience: Software developers
Purpose: Explain CI/CD pipeline workflow
Platform: Technical documentation

### Complete Prompt

```text
Create an infographic with the following specifications:

Topic: Continuous Integration / Continuous Deployment Pipeline
Audience: Software developers and DevOps engineers
Purpose: Technical documentation of deployment workflow

Title: "CI/CD Pipeline Architecture"
Title Position: Top left

Visual Style: Isometric 3D technical style with blueprint aesthetic. Use tech-industry colors (blues, greens) with geometric precision. Modern developer-focused design.

Layout: Flowchart with chevron arrow progression showing 6 sequential stages left to right, then branching decision points, then final deployment.

Color Palette:
- Background: Dark navy (#0A1929)
- Stage boxes: Gradient from dark blue (#1E3A5F) to lighter blue (#2E5984)
- Success paths: Bright green (#00E676)
- Failure paths: Red (#FF5252)
- Active elements: Cyan (#00E5FF)
- Text: White (#FFFFFF) and light gray (#B0BEC5)

Content - 6 Pipeline Stages:

Stage 1: "CODE COMMIT"
- Trigger: Developer pushes code
- Tools: Git
- Icon: Code branch symbol

Stage 2: "BUILD"
- Action: Compile application
- Tools: Maven/Gradle
- Icon: Gear/cog

Stage 3: "TEST"
- Action: Run automated tests
  • Unit tests
  • Integration tests
  • Security scan
- Tools: JUnit, Selenium
- Icon: Checkmark in shield

Stage 4: "QUALITY GATE"
Decision Diamond: "Tests Passed?"
- If YES (green arrow): Continue to Stage 5
- If NO (red arrow): Return to Stage 1 with notification

Stage 5: "STAGING DEPLOY"
- Action: Deploy to staging environment
- Tools: Kubernetes, Docker
- Icon: Server stack

Stage 6: "PRODUCTION"
Decision Diamond: "Manual Approval?"
- If YES: Deploy to production
- If NO: Hold in staging

Final: "LIVE"
- Status: Application running
- Monitoring: Active
- Icon: Globe/world

Dimensions: 1920x1080 pixels (horizontal for wide display)

Technical Details:
- Each stage represented as 3D isometric box with subtle shadow
- Arrows between stages should be thick chevrons in cyan
- Decision diamonds elevated slightly above main flow
- Success paths in green, failure paths in red
- Small tool logos beneath each stage name
- Dashed lines for failure/loop-back paths
- Solid lines for forward progression

Typography:
- Stage names: 28pt bold uppercase
- Stage actions: 18pt regular
- Tool names: 14pt light
- Decision text: 20pt bold

Additional Elements:
- Timeline indicator at top showing typical duration for each stage
- Small notification icon at failure points
- Metrics badge on final stage (uptime, response time)
- Legend in bottom right explaining colors and symbols

Layout Requirements:
- Even spacing between stages
- Clear visual progression left to right
- Decision points clearly elevated
- All text readable on dark background with high contrast
```

### Why This Works

- **Technical audience**: Isometric 3D style appeals to developers
- **Clear workflow**: Chevron progression shows process flow
- **Decision points**: Diamonds clearly show branching logic
- **Visual hierarchy**: Color coding indicates paths (success/failure)
- **Detailed but organized**: Comprehensive information in structured layout

## Example 5: Data Visualization (Complex)

### Context

Target audience: Business executives
Purpose: Quarterly business review presentation
Platform: Executive presentation slide

### Complete Prompt

```text
Create an infographic with the following specifications:

Topic: Q4 2025 Company Performance Metrics
Audience: Executive leadership team and board members
Purpose: High-level quarterly performance overview

Title: "Q4 2025 Performance Dashboard"
Subtitle: "Key Metrics at a Glance"
Title Position: Top center

Visual Style: Executive dashboard style with clean data visualization, corporate professional aesthetic, minimal decoration, focus on clarity and data. Use financial/business color scheme.

Layout: Grid layout (2 rows x 3 columns) with six key metric cards, each containing a primary number, trend indicator, and small chart.

Color Palette:
- Background: Light gray (#F8F9FA)
- Card backgrounds: White (#FFFFFF)
- Positive trends: Green (#28A745)
- Negative trends: Red (#DC3545)
- Neutral/stable: Blue (#007BFF)
- Text: Dark gray (#212529)
- Subtle accents: Medium gray (#6C757D)

Content - 6 Metric Cards:

Row 1:

Card 1: Revenue
- Primary number: "$47.3M"
- Trend: ↑ 23% vs Q3
- Trend color: Green (positive)
- Mini chart: Line graph showing upward trend over 4 quarters
- Label: "Quarterly Revenue"

Card 2: Customer Growth
- Primary number: "12,450"
- Trend: ↑ 18% vs Q3
- Trend color: Green (positive)
- Mini chart: Bar graph showing growth over 4 quarters
- Label: "Active Customers"

Card 3: Profit Margin
- Primary number: "34.2%"
- Trend: ↑ 2.1% vs Q3
- Trend color: Green (positive)
- Mini chart: Area chart showing margin improvement
- Label: "Net Profit Margin"

Row 2:

Card 4: Customer Satisfaction
- Primary number: "4.7/5.0"
- Trend: → Stable
- Trend color: Blue (neutral)
- Mini chart: Horizontal bar showing rating
- Label: "CSAT Score"

Card 5: Churn Rate
- Primary number: "2.8%"
- Trend: ↓ 0.5% vs Q3
- Trend color: Green (positive - lower is better)
- Mini chart: Line graph showing decline
- Label: "Monthly Churn Rate"

Card 6: Team Size
- Primary number: "287"
- Trend: ↑ 12 employees vs Q3
- Trend color: Blue (neutral)
- Mini chart: Simple number with small people icons
- Label: "Total Employees"

Dimensions: 1920x1080 pixels (presentation format)

Card Design Specifications:
- Each card: Rounded corners (8px radius)
- Subtle shadow for depth
- Card padding: 20px all sides
- Primary number: Large, bold, centered at top of card
- Trend indicator: Directly below number with arrow and percentage
- Mini chart: Bottom third of card, subtle gray grid lines
- Label: Small text at very bottom of card

Typography:
- Title: 48pt bold
- Subtitle: 24pt light
- Primary numbers: 56pt bold
- Trend percentages: 28pt semi-bold
- Trend indicators: 32pt (arrow symbols)
- Card labels: 18pt regular
- Chart labels: 12pt light

Additional Requirements:
- Consistent spacing between cards (30px gaps)
- Align all elements within cards for visual consistency
- Use arrow symbols: ↑ (up), ↓ (down), → (stable)
- Mini charts should be minimalist, no axis labels needed
- Include small "Q4 2025" date indicator in top right corner
- Footer text: "Internal Use Only - Board Presentation"

Visual Hierarchy:
- Primary numbers should dominate each card
- Trend indicators clearly visible at second level
- Charts provide supporting visual context
- Labels identify what's being measured
- Overall layout balanced and professional
```

### Why This Works

- **Executive-appropriate**: Clean, professional, data-focused design
- **Grid organization**: Six key metrics easily scannable
- **Visual hierarchy**: Numbers dominate, trends clear, charts support
- **Consistent structure**: All cards follow same format for easy comparison
- **Action-oriented**: Trend indicators immediately show performance direction

## Refinement Example

Starting with Example 1 (Educational Timeline), here's how to refine it:

### Initial Generation

_[Gemini generates the timeline]_

### Refinement Round 1: Text Corrections

```text
Leave everything else exactly the same, but make these text corrections:

1. Change "Altair 8800" description to "First personal computer for hobbyists"
2. Fix spacing between 1995 and 2007 milestones - increase by 15%
3. Increase title font size from current size to 48pt
```

### Refinement Round 2: Visual Adjustments

```text
Keep all content and layout exactly the same, but adjust these visual elements:

1. Make the timeline line 2px thicker
2. Add subtle drop shadow to each icon (2px offset, 30% opacity)
3. Increase contrast by changing background from light gray to pure white (#FFFFFF)
```

### Refinement Round 3: Icon Style

```text
Keep everything identical except:

1. Change all icons from filled style to outline/line-art style
2. Make icon outlines 3px thick
3. Ensure all icons are same size (80px x 80px)
```

## Tips for Adapting These Examples

### For Different Audiences

- **Children**: Simplify language, use cartoon style, bigger fonts, more colors
- **Professionals**: Use technical terminology, minimalist style, subdued colors
- **General public**: Balance simplicity and sophistication, varied styles acceptable

### For Different Platforms

- **Mobile/Instagram**: Increase all font sizes by 30-40%, use vertical format
- **Print**: Specify CMYK colors, increase resolution to 300 DPI
- **Presentation**: High contrast colors, larger fonts (minimum 24pt)

### For Different Content Density

- **Simple (3-5 elements)**: More whitespace, larger elements, clearer hierarchy
- **Medium (6-10 elements)**: Balanced spacing, varied sizes, clear grouping
- **Complex (10+ elements)**: Tight spacing, smaller fonts, strong organization

## Common Modifications

### Changing Color Schemes

Replace color palette section with your brand colors or preferred scheme. Always specify:

- Background color
- Primary content color
- Secondary/accent colors
- Text colors (ensure contrast)

### Adjusting Dimensions

Common dimension presets:

- Instagram Square: 1080x1080
- Instagram Story: 1080x1920
- Facebook Post: 1200x630
- Twitter Post: 1200x675
- LinkedIn Post: 1200x627
- Presentation Slide: 1920x1080
- Print Poster: Scale up to 300 DPI (e.g., 24"x36" = 7200x10800 pixels)

### Adding Brand Elements

Include brand requirements in "Additional Requirements" section:

```text
Brand Requirements:
- Include company logo in bottom right (200px width)
- Use official brand colors: Primary #003366, Secondary #FFD700
- Use brand font: Montserrat for headings, Open Sans for body
- Include website URL in footer: www.company.com
```

## Success Metrics

Good prompts result in outputs that:

1. ✅ Contain no spelling errors or gibberish text
2. ✅ Follow specified layout pattern clearly
3. ✅ Use specified colors accurately
4. ✅ Maintain visual hierarchy as designed
5. ✅ Meet technical specifications (dimensions, format)
6. ✅ Require minimal refinement (0-2 rounds)
7. ✅ Achieve intended purpose (educate, persuade, inform)

Use these examples as templates and adapt them to your specific needs for best results.
