# Layout Patterns for Infographic Design

This reference provides comprehensive guidance on 24+ layout patterns for structuring infographic content.

## Overview

Layout patterns provide structural frameworks that guide how information flows and how viewers navigate content. Select
patterns that match:

- Content structure (sequential, hierarchical, comparative, categorical)
- Information density (simple vs. complex)
- Viewing context (mobile, desktop, print)
- Reading flow (left-to-right, top-to-bottom, circular)

## Pattern Catalog

### 1. Linear Timeline

**Description:** Events or steps arranged in a straight line, typically left-to-right or top-to-bottom. Shows
chronological progression or sequential processes.

**Best for:**

- Historical events
- Project roadmaps
- Step-by-step processes
- Evolution or progression

**Structure:**

```text
[Start] → [Event 1] → [Event 2] → [Event 3] → [End]
```

**Prompt language:**

```text
Layout: Linear timeline flowing left to right with [number] events marked by icons and dates.
```

**Use cases:** Company history, project milestones, historical events, process workflows

---

### 2. Pyramid / Hierarchical

**Description:** Information arranged in pyramid shape with broadest concept at top/bottom narrowing to specifics. Shows
hierarchy, priority, or filtering.

**Best for:**

- Hierarchical information
- Prioritization frameworks
- Filtering processes
- Value propositions

**Structure:**

```text
      [Top Level]
    [Second Level]
  [Third Level]
[Base Level]
```

**Prompt language:**

```text
Layout: Pyramid hierarchy with [number] levels, widest at [top/bottom] narrowing to apex.
```

**Use cases:** Organizational charts, Maslow's hierarchy, sales funnels, priority frameworks

---

### 3. Circular Flow / Cycle

**Description:** Elements arranged in a circle showing continuous or cyclical processes. Indicates no clear beginning or
end, or recurring patterns.

**Best for:**

- Cyclical processes
- Continuous improvement loops
- Interconnected concepts
- Recurring patterns

**Structure:**

```text
     [Element 1]
   ↗           ↘
[Element 4] ← [Element 2]
   ↖           ↙
     [Element 3]
```

**Prompt language:**

```text
Layout: Circular flow with [number] elements in clockwise progression showing continuous cycle.
```

**Use cases:** Product lifecycles, water cycle, continuous improvement, seasonal patterns

---

### 4. Split Screen / Comparison

**Description:** Canvas divided into two or more sections for direct side-by-side comparison. Emphasizes contrasts and
differences.

**Best for:**

- Before/after comparisons
- Pros and cons
- Product comparisons
- Contrasting concepts

**Structure:**

```text
[Left Side]  |  [Right Side]
Content A    |  Content B
Data A       |  Data B
```

**Prompt language:**

```text
Layout: Split screen divided vertically with [Topic A] on left and [Topic B] on right for direct comparison.
```

**Use cases:** Product comparisons, before/after, pros/cons, contrasting solutions

---

### 5. Grid / Modular

**Description:** Information organized in uniform grid with equal-sized cells. Each cell contains independent but
related content.

**Best for:**

- Multiple equal items
- Category organization
- Portfolio displays
- Collection showcases

**Structure:**

```text
[Item 1] [Item 2] [Item 3]
[Item 4] [Item 5] [Item 6]
[Item 7] [Item 8] [Item 9]
```

**Prompt language:**

```text
Layout: Grid layout with [columns] x [rows] uniform cells, each containing [content type].
```

**Use cases:** Product catalogs, team members, feature lists, portfolio items

---

**Best for:**

- Central topic with subtopics
- Mind maps
- Concept relationships
- Hub-and-spoke models

**Structure:**

```text

[Topic 4] ← [Center] → [Topic 2]

        [Topic 3]
```

**Prompt language:**


**Use cases:** Mind maps, concept relationships, service offerings, ecosystem diagrams

```text
[Section 2: Content]
```

### 9. Tree / Branching

**Best for:**

- Family trees
- Taxonomies
- Decision trees
- Organizational structures

**Structure:**


**Prompt language:**


### 10. Iceberg / Hidden vs. Visible

**Description:** Visible portion above waterline with larger hidden portion below. Contrasts apparent vs. underlying

**Best for:**

- Hidden complexities
- Surface vs. depth
- Visible vs. invisible factors
- Cost breakdowns

**Structure:**

```text

[Visible 20%]
-----------------
[Hidden 80%]
```

**Prompt language:**

```text
Layout: Iceberg diagram with [visible elements] above waterline and [hidden elements] below representing larger reality.
```

**Use cases:** Cost analysis, complexity visualization, conscious vs. unconscious, effort breakdowns

## Layout Selection Guidelines

### By Content Type

**Sequential/Process:**

- Linear Timeline
- Vertical Flow
- Staircase
- Flowchart
- Chevron Chain

**Hierarchical:**

- Pyramid
- Tree/Branching
- Layered Stack
- Organizational

**Comparative:**

- Split Screen
- Venn Diagram
- Matrix 2x2
- Zipper/Alternating

**Cyclical:**

- Circular Flow
- Wave Pattern
- S-Curve
- Horseshoe

**Relational:**

- Network/Web
- Hub and Satellite
- Radial Spoke
- Mind Map

**Proportional:**

- Pie Chart
- Iceberg
- Funnel
- Thermometer

### By Information Density

**Low (Simple):**

- Linear Timeline (3-5 items)
- Split Screen (2 sides)
- Staircase (3-5 steps)
- Pie Chart (3-6 slices)

**Medium:**

- Grid 3x3
- Radial with 6-8 spokes
- Flowchart (8-12 steps)
- Tree (2-3 levels)

**High (Complex):**

- Network Web (10+ nodes)
- Layered Stack (5+ layers)
- Detailed Flowchart
- Complex Tree (4+ levels)

### By Platform

**Mobile/Vertical:**

- Vertical Flow
- Staircase
- Linear Timeline (vertical)
- Zipper/Alternating

**Desktop/Horizontal:**

- Linear Timeline (horizontal)
- Split Screen
- Grid Layout
- Chevron Chain

**Print:**

- Radial Spoke
- Venn Diagram
- Matrix
- Pyramid

**Social Media (Square):**

- Circular Flow
- Grid Layout
- Radial Spoke
- Split Screen

## Combining Layouts

Mix layout patterns for complex information:

```text
Layout: Primary pyramid structure with each level containing a horizontal timeline showing progression.
```

Or:

```text
Layout: Central radial hub with each spoke ending in a small grid showing related items.
```

Specify primary structure first, then secondary patterns within sections.

## Layout Best Practices

### Visual Hierarchy

- Place most important information at natural entry points (top-left, center)
- Use size and position to indicate importance
- Guide eye flow with directional cues

### White Space

- Allow breathing room between elements
- Don't overcrowd layouts
- Use margins and padding generously

### Balance

- Distribute visual weight evenly
- Create symmetry where appropriate
- Balance detailed and simple areas

### Flow

- Create clear reading path
- Use arrows or lines to guide navigation
- Make progression obvious

### Consistency

- Maintain consistent spacing
- Use uniform element sizes where appropriate
- Apply consistent styling within layout

## Testing Layouts

Evaluate layout effectiveness:

1. **Clarity**: Can viewers understand the structure immediately?
2. **Flow**: Is the reading order obvious and natural?
3. **Balance**: Does the layout feel visually stable?
4. **Efficiency**: Does it convey information efficiently?
5. **Aesthetics**: Is it visually appealing?

Test with target audience and refine based on comprehension and engagement.
