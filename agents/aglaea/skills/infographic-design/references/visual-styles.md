# Visual Styles Catalog for Infographic Generation

This reference provides comprehensive descriptions of 20+ visual styles for creating infographic prompts with Gemini.

## Overview

Visual style significantly impacts how audiences perceive and engage with infographics. Select styles that match:

- Target audience sophistication and preferences
- Content tone (playful, serious, technical, creative)
- Distribution platform (social media, print, presentation)
- Brand identity and guidelines

## Style Catalog

### 1. Paper Cutout Style

**Description:** Looks like a collage made of construction paper with layered elements, visible edges, and flat colors.

**Best for:**

- Educational content
- Craft and DIY topics
- Children's content
- Approachable, friendly tone

**Prompt language:**

```text
Visual Style: Paper cutout style with layered construction paper look, flat colors, visible edges, and shadow depth.
```

**Use cases:** School projects, craft tutorials, children's education, community events

---

- Kawaii / Cute Vector

- Paper Cutout
- Doodle / Casual Sketch

**Teens (13-18):**

- Comic Book / Pop Art
- Cyberpunk / Neon
- Pixel Art / 8-bit
- Gradient Mesh / Modern

**Young Adults (19-35):**

- Flat Design / Minimalist
- Isometric 3D
- Cyberpunk / Neon
- Gradient Mesh / Modern

**Professionals (35+):**

- Flat Design / Minimalist
- Infographic / Data Viz
- Blueprint / Technical
- Line Art / Monoline

**General Audience:**

- Flat Design / Minimalist
- Hand-Drawn / Sketch
- Infographic / Data Viz
- Geometric Abstract

### By Industry

**Technology:** Cyberpunk, Isometric 3D, Flat Design, Gradient Mesh
**Education:** Kawaii, Cartoon, Paper Cutout, Hand-Drawn
**Business:** Flat Design, Infographic, Line Art, Minimalist
**Healthcare:** Flat Design, Kawaii, Hand-Drawn, Infographic
**Entertainment:** Comic Book, Neon Sign, Cartoon, Pop Art
**Luxury:** Art Deco, Line Art, Photorealistic, Elegant
**Creative:** Watercolor, Geometric Abstract, Hand-Drawn, Painterly

### By Tone

**Professional:** Flat Design, Blueprint, Infographic, Line Art
**Playful:** Kawaii, Cartoon, Doodle, Paper Cutout
**Modern:** Gradient Mesh, Cyberpunk, Isometric, Flat Design
**Artistic:** Watercolor, Geometric Abstract, Hand-Drawn, Mosaic
**Nostalgic:** Retro, Pixel Art, Art Deco, Vintage

## Combining Styles

Combine elements from multiple styles for unique results:

```text
Visual Style: Flat design minimalist base with hand-drawn sketch accents for personality and warmth.
```

Or:

```text
Visual Style: Isometric 3D layout with cyberpunk neon color scheme for futuristic tech aesthetic.
```

Specify primary style first, then secondary stylistic elements to blend.

## Testing and Iteration

Try multiple styles for the same content to compare results. Test audience preference through:

- A/B testing with different style versions
- Gathering feedback on clarity and appeal
- Measuring engagement metrics
- Assessing brand alignment

Refine style choice based on performance data and audience response.
