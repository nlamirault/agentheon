# preview.html Template Guide

The `preview.html` is a standalone visual catalog of the design system. No build step, no server —
just open it in a browser. Use only inline CSS and optionally a Google Fonts `<link>` tag.

## Required sections (in order)

## Implementation notes

- **CSS variables first**: Define every token as a `--variable` at `:root`, then reference them
  throughout the file. This makes the file useful as a reference for implementation.
- **Live rendering**: Typography must render with the actual fonts and sizes, not described in prose.
  An AI should be able to look at the preview and immediately see the design system in action.
- **Hover states**: Add `:hover` rules to buttons and interactive elements — the preview should be
  interactive, not static.
- **Dark mode variant**: If the design system has a dark mode, offer to generate `preview-dark.html`
  as a separate file using the same structure with dark-mode color variables.
- **No external CSS frameworks**: No Tailwind, Bootstrap, etc. Only inline styles and a `<style>` tag.
  The file must work offline (except for font loading).
